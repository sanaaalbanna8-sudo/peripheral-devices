الأجهزة الطرفية والوسائط — عرض تفاعلي
=====================================

افتح الملف:
  index.html

أو شغّل من المجلد:
  python -m http.server 8766
ثم زر:
  http://localhost:8766

الأقسام
--------
1. البداية: تعريف الجهاز الطرفي، ومخطط النظام، ووحدات التصنيف الخمس
2. كل وحدة: تعريف التصنيف ثم أجهزته من نص الكتاب
3. معرض الأجهزة: صورة، اسم عربي، اسم إنجليزي مع سماعة للنطق
4. صفحة الجهاز: لماذا نحتاجه ومتى نشتريه للشركة
5. المصطلحات: Firmware، النص البديل، RSI، الوسائط...

لا يوجد اختبار في هذا المشروع.

المصدر التعليمي: الوحدة 1 — أنظمة تكنولوجيا المعلومات (الإستراتيجية والإدارة والبنية الأساسية)
